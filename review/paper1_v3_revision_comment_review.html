What changed in the 25 July coauthor pass

Sharon Chiang added 13 comments and two substantive tracked passages. The new feedback is methodologically valuable, but it separates into changes that can be made in prose now and analyses that would require a deliberate scope decision and new code.

Resolved in substance

Affiliation 5 now contains the full UCSF department and institute. Verify only the journal’s preferred state/country style. The stale margin comment can then be resolved.

Useful tracked caveat, but too long

The abstract now states that estimates depend on simulator assumptions. Keep that idea, but compress it: the current accepted abstract contains about 258 whitespace-delimited words, while the front matter still says 235, and two abstract lines spill onto an otherwise nearly empty page 4.

Reframe the negative-binomial analysis

Do not call it an independent diagnostic comparator. CHOCOLATES generates counts with a hierarchical gamma–Poisson/negative-binomial-like process, so the fitted NB model is best described as a model-concordant statistical calibration check. Its near-5% result is not evidence of diagnostic superiority or real-world validity.

Add a simulator-transparency package

Add a supplementary parameter table and validation figure covering seizure burden, overdispersion, clustering, multidien periods/amplitudes, cycle length and variability, ovulation/ILP behavior, age, and configured medical modifiers. Report sources, exact settings, applicability, and which assumptions were varied.

Prioritize C3 transparency

Because C3 drives the largest apparent-positive rate, explain exactly how ILP is generated and how C3 is restricted. In the current adapter, nonovulatory cycles and cycles lacking a valid ovulation day or progesterone field are marked ILP; otherwise ILP is assigned when the maximum progesterone on post-ovulation days 5–9 is below 5 ng/mL. C3 then compares O+L+M with F only within flagged cycles.

New analyses require an author-team scope decision

Scenario sensitivity, nonstationary seizure diaries, simulation-driver analyses, a C3 NB model, and an interactive calculator are not copyedits. The first three would materially strengthen the paper if performed prospectively; a clinical-facing calculator should be deferred until empirical validation because a disclaimer cannot prevent patient-specific overinterpretation.

Empirical validation is the right future direction

Keep the new Discussion paragraph, but refine it. Within-person time shifts preserve each diary’s marginal structure, yet ordinary circular shifts create an artificial end-to-start junction and rely on stationarity. Cross-person pairing breaks coupling but requires matching and participant-level resampling. Present these as complementary empirical-null designs, not as proof that any single shift removes biological coupling.

Bottom line

Most revisions improve accessibility, but several should not be accepted as written because they change the scientific meaning or introduce new ambiguity. I would resolve the following before accepting changes globally.

New high-priority decisions

  1. Rename the NB analysis a model-concordant calibration check throughout the abstract, introduction, methods, results, and discussion.
  2. Add the simulator parameter table and distribution-level validation figure; an averages-only cohort table is not enough.
  3. Expose the ILP/C3 algorithm and treat C3 sensitivity to model assumptions as a primary robustness question.

1Correct Table 3’s category labels

The entries are mutually exclusive participant-window categories, not “individual cycle types.” The final 4.6%/4.2% column is C3 with C1 and/or C2, not “Any.” “Any” would include every positive category and therefore cannot be 4.6%.

2Restore the Monte Carlo interval’s true meaning

Table 4’s range is the empirical 2.5th–97.5th percentile interval across simulated studies. It is not a confidence interval. The underlying summary code explicitly computes quantiles.

3Separate “not applicable” from “indeterminate”

C3 is not evaluated in the healthy ovulatory cohort. Reporting 0/50,000, 0% positive, and 100% indeterminate suggests a failed test. Use “Not applicable” or omit the row.

4Do not call discordance an error without a reference standard

A participant’s impression and a diary-derived classification can disagree, but neither is an established gold standard. Frame these as forms of discordance, not proven false positives or false negatives.

5Reject the proposed Nyquist rationale

Nyquist sampling does not justify “four months or six cycles plus four seizure days,” and it does not explain the seizure-day threshold. Describe this as an investigator-selected minimum-data sensitivity unless it was prespecified or taken from prior work.

6Use precise Herzog terminology

Avoid “the Herzog method” and “championed by Andrew Herzog.” Introduce phase definitions and pattern-specific seizure-frequency ratio thresholds introduced by Herzog et al., then use “Herzog criteria” as shorthand.

Proposed title and footnote

Supplementary Table X. Cumulative distributions of simulated Herzog seizure-frequency ratios in three-complete-cycle windows under independence.

Values are cumulative counts and percentages of participant-windows with a defined pattern-specific ratio at or above each listed threshold. Ratios were calculated using strict Herzog phase labeling: C1 = ADSF(M)/ADSF(F+L), C2 = ADSF(O)/ADSF(F+L), and C3 = ADSF(O+L+M)/ADSF(F) in windows with applicable inadequate-luteal-phase cycles. Positive infinite ratios were retained; undefined ratios were excluded from the classifiable denominator and are reported separately. C3 was not applicable to the healthy ovulatory cohort. Bold rows indicate the pattern-specific inflection thresholds reported by Herzog et al. (C1, 1.69; C2, 1.83; C3, 1.62). ADSF, average daily seizure frequency; M, menstrual; F, follicular; O, ovulatory; L, luteal.

Supplementary Figure X — input/output validation

Compare simulated and empirical distributions, not just averages. Candidate panels are seizures/month, seizure days/month, overdispersion, clustering, dominant multidien period and amplitude, cycle length, within-person cycle variability, ovulatory fraction, ILP fraction, age, and modifier prevalence. ECDFs or aligned density/quantile plots are preferable to an overcrowded set of histograms.

When microdata are unavailable

Overlay published medians, quantiles, or target bands and label them as summary-level calibration targets. A visual match to one or two moments is not distributional validation, and no panel should imply empirical validation where only an investigator-selected setting is available.

Robustness, not just Monte Carlo precision

Bootstrap intervals within one simulation setting quantify finite-sample variation under that setting. They do not quantify uncertainty across seizure, cycle, ILP, or nonstationarity assumptions. Report a prespecified scenario envelope or sensitivity distribution separately.

Clinically interpretable language

Call associations with model features simulation drivers of apparent classification, not patient-level clinical risk factors. Defer a calculator until those relations have been checked in real paired diaries.

- Identify or stratify nonstationary segments (for example medication changes or secular trends) before shifting. Do not use data-dependent shift choices selected to produce a desired null rate.
- Generate enough shifts per participant for stable individual and pooled empirical-null summaries.

Empirical-null design B: matched cross-participant pairing
- Pair each seizure diary with menstrual diaries from other participants matched/stratified on age, diary duration, cycle regularity, ovulatory/ILP information, and other available modifiers.
- Prevent self-pairing and document donor reuse. Account for dependence caused by repeated use of the same seizure or menstrual diary.
- Preserve observed missingness and calendar coverage; include sensitivity analyses for seasonality and secular calendar effects.

Inference and comparison
- Resample at the participant level and preserve all shifts/pairs belonging to a participant within a replicate.
- Report classifiable and all-attempted rates, pattern decomposition, empirical-null percentiles, and uncertainty.
- Compare the empirical-null and simulated-null distributions using aligned definitions and stratification, not only averages. Diagnose mismatches in seizure burden, clustering, multidien rhythms, cycle variability, ILP prevalence, and nonstationarity.
- Keep within-shift Monte Carlo uncertainty, participant sampling uncertainty, and design/model uncertainty distinct.
- Treat findings as validation or falsification of specific simulation assumptions, not as an estimate of true catamenial prevalence.

Implementation safeguards
- Write a frozen analysis configuration and synthetic test fixtures before reading outcome summaries.
- Add tests for no self-pairing, permitted shifts, missingness preservation, no leakage across resamples, repeated-donor dependence, definition parity with the simulation pipeline, and deterministic seeds.
- Return the preregistration-style specification first. Then implement only after the required data and governance conditions are confirmed.
